# Қаржы

Пәтерлес студенттерге арналған ортақ шығын есебі және жеке қаржы журналы.
Құрылымы қарапайым: build қадамы жоқ, framework жоқ — үш статикалық файл.

## Локальді іске қосу

```bash
cd ~/Documents/ortaq-qalta
python3 serve.py
```

Содан кейін Chrome-нан **http://localhost:4321** ашасың. Басқа порт керек болса:
`python3 serve.py 8080`.

`index.html` файлын тікелей екі рет басып ашуға да болады, бірақ Chrome
`file://` режимінде деректі басқаша сақтайды — сондықтан әрқашан localhost
арқылы ашқан дұрыс.

## Тірі сайт

**https://ortaq-qalta.vercel.app**

Репозиторий: [zajgalievr-create/qarzhy](https://github.com/zajgalievr-create/qarzhy)

Vercel GitHub-қа байланған, сондықтан деплой автоматты:

```bash
git add -A
git commit -m "не өзгергені"
git push
```

`main` бұтағына пуш жасаған сайын өндірістік нұсқа жаңарады. Басқа бұтаққа
пуш жасасаң, Vercel бөлек алдын ала қарау (preview) сілтемесін береді —
өндірістік сайтқа тимейді.

Қолмен шығару керек болса:

```bash
npx vercel deploy --prod
```

Статикалық сайт — build қадамы жоқ, framework «Other». `serve.py` мен `.claude`
`.vercelignore` арқылы жіберілмейді.

Deployment Protection өшірілген, сондықтан сілтемені білетін кез келген адам
аша алады. Қайта қосу керек болса: Vercel панелі → Project Settings →
Deployment Protection.

## Файлдар

| Файл | Не істейді |
|---|---|
| `index.html` | Беттің қаңқасы, шрифттер, favicon |
| `styles.css` | Дизайн жүйесі: түс токендері, ашық/күңгірт тақырып, компоненттер |
| `app.js` | Бүкіл логика: баланс есептеу, есеп-қисап, интерфейс |
| `store.js` | Дерек қоймасы: Firestore, Claude базасы немесе localStorage |
| `firebase-config.js` | Firebase кілттері (толтырылмаса — localStorage) |
| `firestore.rules` | Firebase консоліне қоятын қауіпсіздік ережелері |
| `serve.py` | Тек локальді дамыту сервері (Vercel-ге қажет емес) |

## Дерек қазір қайда сақталады

`store.js` ішінде — браузердің **localStorage**-інде. Демек:

- ноут пен телефон бір-бірінің дерегін көрмейді;
- браузердің деректерін тазаласаң, есеп те өшеді;
- Баптау → Дерек бөлімінен файлға шығарып, екінші құрылғыға жүктеуге болады.

Артефакт ретінде (claude.ai) ашылса, `store.js` автоматты түрде платформаның
ортақ базасын алады да, синхрон өзінен-өзі істейді.

## Firebase қосу (ортақ синхрон)

Код дайын тұр — тек Firebase жобасын ашып, конфигті қою қалды. Соны істесең,
ноут, телефон және пәтерлестерің бір деректі нақты уақытта көреді.

### 1. Жоба ашу

[console.firebase.google.com](https://console.firebase.google.com) → **Add project**

- Аты: `qarzhy-site`
- Google Analytics — **өшір**, керегі жоқ

### 2. Firestore қосу

Сол жақ мәзір → **Build → Firestore Database → Create database**

- **Production mode** таңда
- Локация: **eur3 (europe-west)** — Қазақстанға ең жақыны

### 3. Аноним кіруді қосу

**Build → Authentication → Get started → Sign-in method → Anonymous → Enable**

Бұл логин экранын шығармайды. Әр браузер фонда өзіне жасырын куәлік алады —
ережелер соны талап етеді, әйтпесе базаны кез келген адам оқи алар еді.

### 4. Конфигті алу

**⚙ Project settings → General → Your apps → `</>` (Web)**

- App nickname: `qarzhy`
- **Register app** → экранда `firebaseConfig` объектісі шығады

Сол мәндерді `firebase-config.js` ішіне көшір:

```js
window.OQ_FIREBASE_CONFIG = {
  apiKey: "AIza...",
  authDomain: "qarzhy-site.firebaseapp.com",
  projectId: "qarzhy-site",
  storageBucket: "qarzhy-site.firebasestorage.app",
  messagingSenderId: "123456789",
  appId: "1:123456789:web:abc123",
};
```

> `apiKey` — құпия кілт емес, жай ғана жобаның идентификаторы. Ол браузерде
> бәрібір ашық тұрады, сондықтан репозиторийге салуға болады. Қауіпсіздікті
> кілт емес, келесі қадамдағы ережелер қамтамасыз етеді.

### 5. Ережелерді қою

**Firestore Database → Rules** → `firestore.rules` файлындағы мәтінді толық
көшіріп қой → **Publish**.

### 6. Қайта шығару

```bash
npx vercel deploy --prod
```

Тексеру: Баптау → Дерек бөлімінде «Firebase» деп тұруы керек. «Осы браузер»
деп тұрса, конфиг қабылданбаған — браузер консолінде себебі жазылады.

### Не қалай қорғалған

- Дерекке тек аноним авторизациядан өткен браузер жетеді.
- Үйдің 6 таңбалы коды мен жеке кілт — құпия сөз рөлінде. Оларды білмеген
  адам жолды таба алмайды.
- Бұл банк деңгейіндегі қорғаныс емес: кодты білетін адам үйдің есебін көреді.
  Студенттің шығын журналына жеткілікті, бірақ шын құпия дерек жазба.

### Қоймасы қалай ауысады

`OQStore.create()` үш көзді осы ретпен қарайды:

1. `window.claude` бар ма — артефакт ретінде ашылса, платформаның ортақ базасы;
2. `firebase-config.js` толтырылған ба — Firestore;
3. әйтпесе — localStorage.

`app.js` қайсысы екенін білмейді: бәрі `doc()`, `collection()`, `onSnapshot()`,
`orderBy()`, `limit()` арқылы жүреді.

## Есептеу логикасы

- Барлық сома **бүтін теңгемен** сақталады, тиын жоқ.
- Тең бөлгенде қалдық бірінші қатысушыларға бір теңгеден таратылады,
  сондықтан баланстардың қосындысы әрқашан дәл нөл болады.
- Есеп-қисап ашкөз алгоритммен ең аз аударым санын шығарады: ең көп қарызы
  бар адам ең көп алуы керек адамға төлейді.
